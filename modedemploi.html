Comment utiliser HIPPOSTAT ?

HIPPOSTAT permet de visualiser et de comparer simplement les performances passées des chevaux engagés dans les courses du jour.

Les graphiques, tableaux de synthèse et outils de filtrage permettent d'obtenir rapidement une vue d'ensemble de la course puis d'approfondir l'analyse des différents partants.

Voici comment utiliser les principales fonctionnalités du site.

1. Choisir une course

Dans la page Programme du jour, sélectionnez la réunion puis la course que vous souhaitez analyser.

HIPPOSTAT charge automatiquement les chevaux engagés ainsi que leurs performances historiques disponibles.

2. Sélectionner les chevaux

La liste des partants permet de sélectionner les chevaux que vous souhaitez étudier plus en détail.

Pour conserver une bonne lisibilité des graphiques, il est conseillé de limiter le nombre de chevaux affichés simultanément.

La sélection peut être modifiée à tout moment afin de comparer différents profils.

3. Obtenir une vue d'ensemble de la course

Le graphique Historique des gains permet de comparer rapidement les gains obtenus par les différents partants sur la période disponible.

Les gains sont répartis selon les classements obtenus, ce qui permet de distinguer visuellement les chevaux ayant régulièrement obtenu de bons résultats.

Le tableau Synthèse des partants complète cette première lecture avec plusieurs indicateurs.

  • la musique des 5 dernières performances ;
  • le nombre de courses ;
  • le nombre de victoires ;
  • le nombre de Top 3 ;
  • le pourcentage de Top 3 ;
  • les gains cumulés ;
  • le gain moyen par course.

4. Analyser l'évolution des performances

Le graphique Évolution des performances présente chronologiquement les participations passées des chevaux sélectionnés.

Chaque bulle correspond à une course historique. Sa position permet notamment de visualiser le classement obtenu lors de cette course.

Cette représentation permet de rechercher rapidement :

  • la régularité d'un cheval ;
  • une progression récente ;
  • une baisse de performance ;
  • des performances remarquables ;
  • des différences selon les conditions rencontrées.

Les situations particulières telles que les disqualifications, les chevaux non classés ou certains résultats particuliers sont identifiées séparément lorsqu'elles sont disponibles.

5. Examiner une performance en détail

La taille des bulles apporte une information supplémentaire permettant de mieux apprécier le niveau de la performance représentée.

Une bulle plus importante permet notamment d'identifier rapidement une performance réalisée dans une course présentant un enjeu financier plus élevé.

Placez simplement le curseur de la souris sur une bulle pour afficher une infobulle contenant les informations disponibles concernant cette participation.

  • date de la course ;
  • hippodrome ;
  • discipline ;
  • distance ;
  • nombre de partants ;
  • classement ;
  • allocation de la course ;
  • gain ;
  • jockey ou driver ;
  • temps et réduction kilométrique lorsqu'ils sont disponibles.

6. Rechercher les confrontations directes

Le filtre Confrontations directes permet d'isoler les courses dans lesquelles plusieurs chevaux sélectionnés se sont déjà affrontés.

Lorsqu'il est activé, l'historique est limité aux courses communes entre les chevaux sélectionnés.

Cette fonctionnalité permet de comparer plus facilement les performances obtenues lorsque plusieurs concurrents de la course du jour ont participé à une même course par le passé.

Pour utiliser ce filtre, sélectionnez au moins deux chevaux puis activez Confrontations directes.

7. Comparer les chevaux

L'un des principaux intérêts de HIPPOSTAT est de pouvoir croiser plusieurs niveaux de lecture avant d'établir sa propre analyse.

Le graphique des gains donne une première vue d'ensemble, tandis que le tableau de synthèse et l'historique des performances permettent d'approfondir l'étude des chevaux sélectionnés.

Les confrontations directes apportent un niveau d'analyse supplémentaire lorsqu'elles existent dans l'historique disponible.

Ces différentes informations peuvent notamment aider à identifier :

  • les chevaux les plus réguliers ;
  • les chevaux en progression ;
  • les profils présentant une forme récente intéressante ;
  • les chevaux ayant déjà bien performé face à certains concurrents ;
  • les performances obtenues dans des conditions comparables.

HIPPOSTAT est un outil d'analyse

HIPPOSTAT ne fournit pas automatiquement de pronostic.

Les performances passées constituent des éléments d'analyse mais ne permettent pas de prévoir avec certitude le résultat d'une course future.

L'objectif est de rendre les informations historiques plus faciles à lire, à comparer et à interpréter afin que chaque utilisateur puisse construire sa propre analyse.
