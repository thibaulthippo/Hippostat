Comment utiliser HIPPOSTAT ?

HIPPOSTAT permet de visualiser et de comparer simplement les performances passées des chevaux engagés dans les courses du jour.

Voici comment utiliser les principales fonctionnalités du site.

1. Choisir une course

Dans la page Programme du jour, sélectionnez la réunion puis la course que vous souhaitez analyser.

HIPPOSTAT charge automatiquement les chevaux engagés ainsi que leurs performances historiques disponibles.

2. Sélectionner les chevaux

La liste des partants permet de choisir les chevaux que vous souhaitez afficher dans les graphiques.

Vous pouvez ainsi limiter l'affichage à quelques chevaux afin de faciliter leur comparaison.

3. Lire l'historique des performances

Chaque cheval sélectionné apparaît dans le graphique avec ses participations passées.

Chaque bulle correspond à une course historique.

Sa position permet notamment de visualiser le classement obtenu lors de cette course.

Les situations particulières telles que les disqualifications, les chevaux non classés ou les résultats absents sont identifiées séparément.

4. Comprendre la taille des bulles

Toutes les performances n'ont pas nécessairement la même importance.

La taille des bulles apporte une information supplémentaire permettant de mieux apprécier le niveau de la performance représentée.

Une bulle plus importante permet notamment d'identifier rapidement une performance réalisée dans une course présentant un enjeu financier plus important.

5. Afficher le détail d'une performance

Placez simplement le curseur de la souris sur une bulle.

Une infobulle apparaît et présente les informations disponibles concernant cette participation.

  • date de la course ;
  • hippodrome ;
  • discipline ;
  • distance ;
  • nombre de partants ;
  • classement ;
  • allocation de la course ;
  • gain estimé ;
  • jockey ou driver ;
  • temps et réduction kilométrique lorsqu'ils sont disponibles.

6. Comparer les chevaux

L'intérêt principal de HIPPOSTAT est de pouvoir comparer visuellement plusieurs chevaux d'une même course.

La représentation graphique permet notamment de rechercher plus facilement :

  • la régularité d'un cheval ;
  • une progression récente ;
  • une baisse de performance ;
  • des performances remarquables ;
  • des différences selon les conditions rencontrées.

HIPPOSTAT est un outil d'analyse

HIPPOSTAT ne fournit pas automatiquement de pronostic.

Les performances passées constituent des éléments d'analyse mais ne permettent pas de prévoir avec certitude le résultat d'une course future.

L'objectif est de rendre les informations historiques plus faciles à lire, à comparer et à interpréter.
